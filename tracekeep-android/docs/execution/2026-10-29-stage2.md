## 实际执行的操作

1. **模块结构调整**：`core:storage` 由 Android library 改为**纯 Kotlin JVM 模块**（存储逻辑只使用文件 API，Android 层仅传入应用私有目录；JVM 化后单元测试无需模拟器且独立验证器可复用字节级格式）——记入 D-014。
2. **版本目录扩展**：新增 `kotlinx-serialization-json 1.8.1`（Maven Central 元数据核实存在）+ `kotlin-serialization` 插件（版本随 Kotlin 2.1.21）。
3. **`core:model` 实现**（10 个新文件 + 2 个测试类）：
   - `SessionState` 状态机（CREATED/RECORDING/PAUSED/STOPPED/SEALED/ABORTED + 迁移真值表；SEALED 只能经封存流程进入）；
   - `RecordingType`、`FileRole`（ORIGINAL/DERIVED）、`FileLifecycle`（REGISTERED/FINALIZED/INCOMPLETE）、`VerificationStatus`（PASS/FAIL/MISSING/UNFINISHED/UNREADABLE 五分类）、`EventSource`（四类来源）、`EventTypes` 常量；
   - `EvidenceSession`/`EvidenceFile`/`EvidenceEvent`/`EvidenceLocation`/`FileRegistry`/`SealRecord` 序列化结构（formatVersion=1 版本化）；
   - `EvidenceJson` 统一编码配置（encodeDefaults 保证字节级可复现）；`TimeProvider` 时间源抽象（可注入模拟跳变）。
4. **`core:storage` 实现**（3 个新文件 + 2 个测试类）：
   - `AtomicFiles`：临时文件 + fsync + ATOMIC_MOVE 原子替换（账本类文件）；`appendLine` 追加 + fsync（事件日志/定位）；
   - `PathSafety`：会话 ID 白名单正则、相对路径穿越防护（`..`/绝对路径/反斜杠/错误根目录）、`resolveInside` 双重防线；
   - `EvidenceStore`：会话创建/加载/列举；状态迁移 + 事件联动；文件登记（ORIGINAL 必须无来源、DERIVED 必须指向 ORIGINAL）；`finalizeFile`（流式 SHA-256 + 大小）；`markFileIncomplete`；`verifyFile`（五分类）；追加式事件日志与定位日志（读取跳过坏行并计数，**不改写原文件**）；`seal()`（REGISTERED→INCOMPLETE 如实标记 + 逐文件校验快照 + 事件/定位摘要 + 异常标志）；`verifySeal()`（严格重算比对）；`recoverOnStartup()`（CREATED/RECORDING/PAUSED → ABORTED + 未完成文件标记 + 观察事件）。
5. **测试修复过程中发现并修复了一个真实实现缺陷**（破坏性测试价值体现）：
   - 初版 `verifySeal` 仅比较登记表元数据，**封存后篡改媒体文件会被误判为「与封存一致」**（假阳性——正对应需求 §12 红线「验证结果存在假阳性」）。修复为：对 FINALIZED 文件重算实际字节摘要与封存哈希比对，同时保留登记哈希未改写检查；新增 3 项对应破坏性测试（篡改媒体/追加伪造事件行/删除文件）。
6. **构建与测试实测**：`./gradlew :core:model:test :core:storage:test :app:assembleDebug`。
