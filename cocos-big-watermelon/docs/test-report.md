## 5. v1.0.2 / v1.0.3 增量验证（洗牌重排与飞行 / 暂停菜单层级）

Web 自动化四套件全部通过（36+7+18+16 = 77 项断言）：

洗牌（test4 16 项 + test3 更新项）：
- 洗牌后水果位置真实改变（存在位移 >25 的水果，行内均匀展开至全宽，spread≈280）
- 数量/等级/分数完全不变（三阶段：全体置 Static → 逐个传送 → 统一转 Dynamic 垂直弹跳；静态体之间无接触，布局避免同 ID 左右相邻 + 行间 12px 垂直间隙，杜绝意外合成）
- 空场洗牌安全、单水果洗牌生效、锁定期内重复点击安全忽略、洗牌后投放/合成/边界正常
- 明显弹跳：弹起高度为直径 0.8~1.5 倍，采样到向上速度 >100 的水果

暂停层级：
- 弹窗层（菜单/暂停/结算）zIndex=1000，高于水果（0），水果不再遮挡菜单
- 下落中暂停：水果完全静止；暂停期间点击被菜单层吞掉不穿透投放；菜单按钮可点（继续）
- 洗牌动画期间暂停：水果冻结、洗牌锁保持，恢复后洗牌完成并解锁
- 多次暂停/继续不重复创建 UI

版本号：`versionName 1.0.1→1.0.2`、`versionCode 2→3`，aapt2 校验 Debug/Release APK 元数据一致。

模拟器（API 33）：安装 v1.0.2/v1.0.3、启动、洗牌前后截屏、暂停菜单遮挡验证（截图存 /tmp/emu_shots/）。

### v1.0.3 洗牌重设计（抛物线飞行）
- 洗牌改为 update 驱动的二次贝塞尔飞行：弹起→空中横移→落到新位置，弧顶为直径 0.8~1.5 倍（Web 实测 rises=45/37/41px），各水果 30ms 错时启动，单球飞行 0.55~0.75s
- 布局生成加入有限次（6 次）随机置换择优，最大化"明显移动"的水果数；杜绝瞬移观感与位移为 0 的批量情况
- 飞行期间水果刚体保持 Static（静态体间无接触），全部落位后统一转回 Dynamic、清空旧速度、恢复下落加速管理；游戏结束时兜底恢复
- 暂停天然冻结飞行（update 仅在 PLAYING 推进）；洗牌锁期间禁投放/撤销/重复触发
- 回归：四套件 36+7+18+16=77 项全部通过；模拟器截屏确认飞行弧线、散布落位（左/中/右）、暂停层级正确
- 版本：1.0.2/3 → 1.0.3/4（aapt2 实测一致）

## 7. 未验证项目与已知问题

1. **真机未验证**：本机无 Android 真机连接，仅模拟器验证；真机刘海/挖孔安全区表现未实测（UI 已按边距避让设计，且全屏沉浸模式下系统提示一次性教育浮层后不再出现）。
2. **音频实际出声**未人工确认（模拟器无音频输出路由），音效播放调用与开关逻辑已通过代码路径与 Web 端验证。
3. 位图数字字体 myFont 仅含数字，分数显示正常；中文文本使用系统字体，Android 上依赖系统中文字体（现代 Android 均自带，模拟器渲染正常）。
4. Web 调试构建左上角的 FPS 统计浮层仅 web-mobile debug 构建存在，APK 中同样存在（Creator debug 构建特性），Release 构建不含。
5. 撤销栈上限 50 步（超出后丢弃最早快照），属设计取舍而非次数限制。
6. 洗牌后水果落定过程中若发生同级接触会正常合成并加分（游戏机制，非缺陷）。
7. Android 返回键行为为"退后台 + 自动暂停"（原生模板 Java 层 moveTaskToBack + JS 层 EVENT_HIDE 暂停），非弹出暂停面板；回前台后显示暂停面板，状态不丢失。
