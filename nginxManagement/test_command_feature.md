# 命令执行功能测试指南

## 测试步骤

### 1. 启动后端服务
```bash
cd backend
go run main.go
```

### 2. 构建前端
```bash
cd frontend
npm run build
```

### 3. 访问应用
打开浏览器访问 `http://localhost:8080`

### 4. 测试命令执行功能

#### 4.1 基本命令测试
1. 点击左侧导航菜单中的"命令执行"
2. 在命令输入框中输入 `dir`
3. 点击"执行"按钮
4. 观察执行结果和记录

#### 4.2 快捷命令测试
1. 点击页面上的快捷命令按钮（如 `ipconfig`）
2. 观察命令是否自动执行
3. 查看执行结果

#### 4.3 记录查看测试
1. 执行几个不同的命令
2. 在记录表格中查看所有记录
3. 点击"查看详情"查看单个记录的完整信息

#### 4.4 记录管理测试
1. 点击"清空记录"按钮
2. 确认记录是否被清空

### 5. API接口测试

#### 5.1 执行命令
```bash
curl -X POST http://localhost:8080/api/command/execute \
  -H "Content-Type: application/json" \
  -d '{"command": "echo Hello World"}'
```

#### 5.2 获取记录
```bash
curl http://localhost:8080/api/command/records
```

#### 5.3 清空记录
```bash
curl -X DELETE http://localhost:8080/api/command/records
```

## 预期结果

### 成功情况
- 命令能够正常执行
- 执行结果正确显示
- 记录能够正确保存和查看
- 页面响应正常

### 错误处理
- 无效命令会显示错误信息
- 网络错误会显示相应提示
- 页面不会崩溃

## 常见问题

### 1. 命令执行失败
- 检查后端服务是否正常运行
- 确认命令在Windows CMD中可执行
- 查看后端日志了解错误原因

### 2. 页面无法访问
- 确认前端已正确构建
- 检查端口8080是否被占用
- 查看浏览器控制台错误信息

### 3. 记录不显示
- 刷新页面重新加载
- 检查 `command_records.json` 文件是否存在
- 确认文件权限正确

## 性能测试

### 1. 并发测试
- 同时执行多个命令
- 观察系统响应情况
- 确认记录正确保存

### 2. 大量记录测试
- 执行大量命令生成记录
- 观察页面加载性能
- 测试清空记录功能

## 安全测试

### 1. 命令注入测试
- 尝试执行危险命令
- 确认系统安全性
- 验证权限控制

### 2. 文件访问测试
- 尝试访问系统文件
- 确认访问权限限制
- 验证安全边界
