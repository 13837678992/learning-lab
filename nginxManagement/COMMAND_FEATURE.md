# 命令执行功能说明

## 功能概述

新增的命令执行功能允许用户通过Web界面执行Windows CMD命令，并自动记录所有操作历史。每次执行的命令都会被保存，包括命令内容、执行结果、执行时间等信息。

## 主要特性

### 1. 命令执行
- 支持执行任意Windows CMD命令
- 实时显示执行状态（执行中、成功、失败）
- 记录命令的标准输出和错误输出
- 显示命令执行耗时

### 2. 操作记录
- 自动保存所有命令执行记录
- 记录包含：命令ID、命令内容、执行状态、开始时间、结束时间、执行时长、输出结果、错误信息
- 记录持久化保存到JSON文件

### 3. 记录管理
- 查看所有执行记录列表
- 查看单个记录的详细信息
- 清空所有记录
- 按时间倒序显示记录

### 4. 用户界面
- 现代化的Web界面
- 常用命令快捷按钮
- 实时状态显示
- 响应式设计

## 使用方法

### 1. 访问命令执行页面
在左侧导航菜单中点击"命令执行"进入功能页面。

### 2. 执行命令
- 在命令输入框中输入要执行的命令
- 点击"执行"按钮或按回车键执行命令
- 系统会显示执行状态和结果

### 3. 使用快捷命令
页面提供了常用命令的快捷按钮：
- `dir` - 查看当前目录内容
- `ipconfig` - 查看网络配置
- `netstat -an` - 查看网络连接状态
- `tasklist` - 查看进程列表
- `ping 127.0.0.1` - 测试本地网络连接

### 4. 查看记录
- 在"执行记录"表格中查看所有历史记录
- 点击"查看详情"按钮查看单个记录的完整信息
- 点击"清空记录"按钮删除所有历史记录

## API接口

### 执行命令
```
POST /api/command/execute
Content-Type: application/json

{
  "command": "要执行的命令"
}
```

### 获取所有记录
```
GET /api/command/records
```

### 获取单个记录
```
GET /api/command/records/:id
```

### 清空记录
```
DELETE /api/command/records
```

## 数据存储

命令记录保存在 `command_records.json` 文件中，包含以下字段：

```json
{
  "id": 1,
  "command": "dir",
  "output": "命令的标准输出",
  "status": "success",
  "startTime": "2024-01-01T12:00:00Z",
  "endTime": "2024-01-01T12:00:01Z",
  "duration": 1000,
  "errorMsg": "",
  "createdAt": "2024-01-01T12:00:00Z"
}
```

## 安全注意事项

1. **命令执行权限**：系统会以当前用户权限执行命令，请谨慎执行高权限命令
2. **命令验证**：建议在执行前验证命令的正确性和安全性
3. **记录清理**：定期清理不需要的历史记录以节省存储空间
4. **网络安全**：确保Web界面只对授权用户开放

## 技术实现

### 后端
- **语言**：Go
- **框架**：Gin
- **并发控制**：使用sync.RWMutex保证线程安全
- **命令执行**：使用os/exec包执行Windows CMD命令
- **数据持久化**：JSON文件存储

### 前端
- **框架**：Vue 3
- **UI库**：Element Plus
- **路由**：Vue Router
- **HTTP客户端**：Axios

## 故障排除

### 常见问题

1. **命令执行失败**
   - 检查命令语法是否正确
   - 确认命令在Windows CMD中可正常执行
   - 查看错误信息了解具体原因

2. **记录不显示**
   - 刷新页面重新加载记录
   - 检查后端服务是否正常运行
   - 查看浏览器控制台是否有错误信息

3. **页面无法访问**
   - 确认后端服务已启动
   - 检查端口8080是否被占用
   - 查看后端日志了解错误信息

### 日志查看
后端日志会显示命令执行的详细信息，包括：
- 命令执行开始和结束时间
- 执行结果状态
- 错误信息（如果有）
